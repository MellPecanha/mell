# Portfólio — Mell Peçanha

Portfólio pessoal de **Mell Peçanha**, desenvolvedora Full Stack com foco em TypeScript, Node.js e APIs REST.

O site apresenta projetos em destaque, trajetória profissional e formas de contato em uma interface responsiva.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Recursos

- Layout responsivo para desktop e dispositivos móveis
- Alternância entre português e inglês
- Tema claro e escuro, com preferência persistida no navegador
- Menu de navegação móvel
- Acessibilidade semântica e preferência por redução de movimento

## Como executar

Como é um site estático, basta abrir o arquivo `index.html` em um navegador.

Para uma experiência de desenvolvimento melhor, use um servidor local, por exemplo:

```bash
npx serve .
```

Em seguida, acesse o endereço exibido no terminal.
